上一章我们完成了电脑版的安装与启动，这一章来做手机版——在安卓手机上运行 Minecraft 国际版 Java 版。

准备工作 ​

首先我们需要准备一台能够正常上网的手机，能打开浏览器即可。

下载 FCL 启动器 ​

手机上玩 Java 版，需要一个专门的启动器。这一章我们用的是 FCL（Fold Craft Launcher）——一款开源免费的安卓端 Minecraft Java 版启动器，它会在手机上运行一套完整的 Java 环境，让你玩到和电脑上一样的 Java 版。

第二步，访问我的网站来获取对应的下载地址。

这里我以原版 GitHubFCL 链接来作为演示，也可以前往我对应的云盘进行下载。

安装 FCL ​

这里我们来进行对应的安装。

安装好后会获得如上图的一个游戏图标 FCL，然后点击打开它。

首次启动配置 ​

同意这里的授权，并阅读声明。

这里需要下载对应的 Java 版本和一些运行环境，点击「安装更新」按钮就可以。

随后我们会进到一个主页，这里会显示当前没有版本和用户名。

下载游戏 ​

我们点击「启动」按钮，可以进入下载页面，选择自己想要的版本。这里以 26.2 作为演示。

如果你暂时不需要安装模组，可以不选择模组，直接点击圆圈里的「下载」按钮。

下载成功后会有如图的提示。

创建离线账户 ​

然后我们点击「没有账户」的位置，来创建一个离线账户。

我这里以我的离线账户 liveou 作为演示。创建好后，你应该能看到如图的界面。

启动游戏 ​

然后点击「启动」按钮，即可见到 Mojang 页面，这时候游戏已经开始启动了。

看到如图所示，就代表你已经成功启动了 Java 版 26.2。

如果这里你的语言是英文状态，可以点击中下方的地球图标来切换成中文。

创建世界，进入游戏 ​

我这里以创建一个新的世界、游戏模式为创造模式来作为演示。

点击「创建新的世界」按钮之后，会出现如图界面，它正在生成地图并进入游戏。

随后你就可以看到如图画面——你已经成功地在手机上进入了 Minecraft Java 版的世界！

已知问题 ​

当前版本在生成海洋的时候，对水的渲染有一些问题，可以尝试切换不同的版本来规避。

至此，手机上安装和游玩 Minecraft 国际 Java 版已经全部完成。
