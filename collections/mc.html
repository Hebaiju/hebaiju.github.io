MC 从0—"∞"

发表于2026-09-02

本教程将教你从0基础不懂任何“MC玩家”→变成“MC大佬”。 这个合集叫「从零到无穷」，路线全程铺好，跟着走就行。

这个系列写给谁 ​

  • 零基础新人：没碰过 MC、或者刚听说想入坑——从第一章开始照着做，装好游戏、成功走进自己的世界
  • 有基础的玩家：已经会玩，想加模组、联机、进服务器——按左侧目录直接跳到需要的章节
  • 高级读者：想弄懂模组原理、自己动手写模组——后面的模组开发部分会从头讲起，不会突然劝退

视频教程相结合 ​

  • 我将会和视频教程相结合来进行一步一步进行标注，保证稳定的来完成

为什么写这个系列 ​

目前的网络环境对新人不算友好：

  • 资源冗杂：下载站、广告、捆绑安装混杂，很难找到正确的东西
  • 教程虽多，坑也多：很多配置教程只讲一半，或者版本过时，照着做总会在某个环节卡住

所以有了这个合集：一套从零开始、步骤完整、跟着做就能成功的教程，并且会一直写下去。

系列路线图 ​

  1. 装好游戏：安装 Java 环境 → 安装启动器 → 成功进入游戏
  2. 正常游玩：单人游戏入门；讲清楚正版账号 / 离线账号的区别与选择
  3. 多人游戏：进服务器、和朋友联机
  4. 开服：成为一个MC腐竹
  5. 模组之路：模组的使用与添加，最后到模组开发

每完成一步都有一个明确的结果，不会学着学着不知道自己在哪。

开始之前，你需要准备 ​

  • 一台电脑：对配置没什么要求，Windows 7 / 10 / 11 都可以，本系列以 Windows 11 演示
  • 能联网：下载 Java、启动器和游戏资源都需要
  • 前期不需要：编程基础和正版账号。到模组开发部分会需要一点 Java 编程，到时候会从头讲

关于游戏版本 ​

Minecraft Java 版更新很频繁，本教程基于 【java-26.2】 编写（更新于 2026-9-1）。不同版本界面和部分设置会有差异，但整体流程一致，遇到不一样的地方以教程思路为准。

怎么使用这个系列 ​

  • 新人按左侧目录从上往下照着做，不要跳步——每一步都是下一步的地基
  • 有基础的读者按需跳读即可
  • 每章末尾都有「常见问题」，出问题先去那里找
  • 还是解决不了？在本页评论区留言，把报错信息或截图发出来即可
